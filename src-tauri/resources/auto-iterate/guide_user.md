# 提示词自动迭代脚本

## 用途

如果你在用 Claude、Codex 这类 agent 工具，把这个脚本交给它，agent 就能帮你自动跑提示词测试，并根据测试结果持续修改提示词。

## 使用方法

1. 下载并安装「黑猫-自动评测台」
2. 建一个工作目录，把被测提示词、评测提示词、数据集放进去。
3. 打开「① API 配置」，页面底部是「自动迭代脚本」。选择这个工作目录，点「复制引导语」。
4. 把复制到的这句话发给 agent，agent 会读取安装目录里的说明，带你完成剩下的操作。

## 建议

第一次建议自己先跑一遍，配置好 API、提示词和数据集，确认能正常出结果。之后就可以让 AI 帮你批量跑、自动改。当然，如果使用脚本，AI 也会读取使用说明教你配置好。
