# 提示词自动迭代脚本

## 用途

如果你在用 Claude、Codex 这类 agent 工具，把这个脚本交给它，agent就能帮你自动跑提示词测试，并根据测试结果持续修改提示词。

## 使用方法

1. 下载并安装「黑猫-自动评测台」
2. 打开「① API 配置」，点页面底部的「导出脚本包」，选一个文件夹。
3. 把被测提示词、评测提示词、数据集放进这个文件夹。
4. 打开文件夹里的「怎么用.txt」，把里面那句话复制给你的 agent：

> 请读取工作目录：<导出目录> 并阅读使用说明：说明文档/自动迭代_说明.md

5. agent 会读取使用说明，带你完成剩下的操作。

## 建议

第一次建议自己先跑一遍，配置好 API、提示词和数据集，确认能正常出结果。之后就可以让 AI 帮你批量跑、自动改。当然，如果使用脚本，AI也会读取使用说明教你配置好。
