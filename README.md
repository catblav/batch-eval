# 黑猫-自动评测台

本地桌面工具。填好自己的 LLM API，批量跑评测数据，按评测提示词给出的分类统计结果。
（更新）新增自动脚本，接入agent可自动跑测评数据，自动迭代提示词。

支持win和mac。

![分析页](docs/screenshots/05-analysis.png)


## 安装

从 [Releases](https://github.com/catblav/batch-eval/releases/latest) 下载对应平台的安装包。

### Windows

下载 `Heimao-AutoEval_<版本>_x64-setup.exe` 运行安装。

### macOS

下载 `Heimao-AutoEval_<版本>_macOS_universal.dmg`，打开后把应用拖进 Applications。包里同时有 Apple Silicon 和 Intel 两种架构。

安装包没有做 Apple 公证，第一次打开要**右键点图标选打开**。如果系统仍然拦截，在终端执行：

```bash
xattr -cr "/Applications/黑猫-自动评测台.app"
```

## 使用

### 1. API 配置

首先进入API 配置页面，配置用于测试的API和评测模型的API，可填写：Base URL、API Key、模型名和生成参数。同一套API配置方案可以被多个提示词运行方案引用。

可以从 OpenAI / DeepSeek / 通义 / Anthropic / 本地模板填入，填完点 **测试连接** 验证，点 **测速** 看实际延迟和 tok/s。

![API 配置](docs/screenshots/01-api.png)

### 2. 提示词配置

在提示词配置页面，可填写被测的提示词和评测提示词，并绑定对应数据集。

预览页会按数据行显示实际发送给两侧 API 的完整内容，方便检查变量替换。缺绑定或提示词时，方案列表和运行页都会标出原因。

![提示词配置](docs/screenshots/02-prompts.png)

### 3. 数据集

导入或粘贴数据，生成数据集，可以同时保存多份。格式支持 CSV、TSV、Excel、JSON、JSONL 和纯文本。

数据集可以被多个方案引用；替换数据不会影响历史任务。

![数据集](docs/screenshots/03-dataset.png)

### 4. 运行

新建任务时勾选一个或多个方案，每个方案各自生成一个独立任务。可以设置任务名称前缀、每个任务的并发数和失败重试次数。

任务之间互不影响：各自进度、各自取消、各自断点续跑。同时最多运行 4 个任务。

运行过程中可以选中任一任务看实时明细；中断后重开应用，任务标记为已中断，可以继续跑没跑完的部分，失败项也可以单独重跑。

![运行](docs/screenshots/04-run.png)

### 5. 分析

顶部下拉选择一条任务记录，左右箭头切换上一条 / 下一条。包含已完成、已取消和已中断的任务；运行中的任务请到运行页看实时明细。

支持查看通过率、有效样本、未计入数量、平均响应时间和错误分类分布，点分类可以筛选。

下面是明细表，支持按结果、分组、分类筛选和关键词搜索。点任意一行打开详情，能看到原始数据、实际发送的消息、被测模型的输出、裁判模型的原始输出和判定原因。

![分析明细](docs/screenshots/06-detail.png)

## 自动迭代脚本

### 用途

如果你在用 Claude、Codex 这类 agent 工具，把这个脚本交给它，agent 就能帮你自动跑提示词测试，并根据测试结果持续修改提示词。

### 使用方法

脚本和说明在安装目录的 `auto-iterate/` 下，不进界面。把说明文件路径和工作目录交给 agent（claude code / codex 等），剩下的流程由 agent 引导你完成：放提示词和数据集，然后读文件、跑测试、改提示词。

### 建议

第一次建议自己先跑一遍，配置好 API、提示词和数据集，确认能正常出结果。之后就可以让 AI 帮你批量跑、自动改。当然，如果使用脚本，AI 也会读取使用说明教你配置好。

## 数据处理

评测分类来自评测提示词输出的错误分类，工具本身不内置任何分类。

**只有以下三种情况**会用工具自带的分类，并且和用户分类分开统计：

- 被测模型调用失败
- 评测模型调用失败
- 评测输出解析失败

输入超过上下文的会做截断，保留头 60% 和尾 40%，详情里会标记。

## 数据存储

配置和数据都在本地用户目录下：

```
Windows:  %APPDATA%\com.batcheval.desktop\
macOS:    ~/Library/Application Support/com.batcheval.desktop\
```

```
settings.json                连接库、方案库、主题、并发与重试设置
datasets/index.json          数据集索引（名称、行数、列名、来源）
datasets/<id>.json           数据集内容
dataset.json                 当前方案的数据集镜像，供自动迭代脚本读取
runs/<runId>/meta.json       任务元信息（方案 / 数据集 / 连接快照、状态、汇总）
runs/<runId>/results.jsonl   每跑完一条追加一行
runs/<runId>/dataset.json    本任务使用的数据集快照
```

**自动保留最近 10 个已完成任务**，超过时删掉最旧的一份；运行中和已中断的任务不自动删除。断点续跑和失败重跑不会新增记录。

每个任务独立保存当时的方案提示词、连接参数（不含 API Key 和接口地址）和原始数据行，所以改方案、换数据集都不影响历史记录的明细、完整报告和导出。

历史任务可在分析页手动删除，删除后磁盘上的结果文件一并移除。

**API Key 明文保存在本地**，不会发送到其它地方。

## 详细功能

### API 配置

- 多条命名连接，可复制、重命名、删除，重启后保留
- 被测和评测各选一条连接，不同方案可以复用或各用各的
- 可配上下文长度、`max_tokens`、`temperature`、`top_p`、超时、自定义请求体与请求头
- 「测试连接」验证连通性；「测速」发 3 次短请求，给出实际延迟和 tok/s
- 删除被方案引用的连接前，会列出受影响的方案

### 提示词配置

- 多套命名方案，每套绑定自己的数据集、被测连接和评测连接
- 主体提示词作为被测模型的 system prompt
- 用户消息模板用 `{{列名}}` 注入数据列，可点击变量插入
- 评测提示词包含 `{{input}}`（被测模型收到的提示词 + 本条输入）和 `{{output}}`（被测模型的实际输出）
- 「预览」按数据行显示三段实际输入
- 缺绑定、缺提示词、变量引用不存在的列都会就地提示
- 「运行此方案」跳到运行页并勾选，不直接开跑

### 数据集

- 多份命名数据集，可导入、粘贴、重命名、替换、删除
- 支持 CSV、TSV、Excel、JSON、JSONL 和纯文本
- 只加载索引和分页预览，大数据集不会在启动时全部读进内存
- 重复列名自动去重，坏行跳过并提示
- 方案的用户消息模板可点击列名插入变量，也可按数据集列一键生成
- 删除被方案引用的数据集前会列出影响；被运行中任务引用时直接拦住

### 运行

- 一次勾选任意多个方案，每个方案独立成任务并行跑
- 每个任务独立的目录、进度、取消、续跑和重跑
- 同时最多 4 个运行中任务；启动前统一校验每个方案
- 同一连接上的多个任务共享 429 退避，避免一起打爆配额
- 连续多条调不通只中止当前任务，不影响其它任务
- **断点续跑**（校验数据集快照）、**失败项重跑**（校验提示词快照）、**取消立即生效**
- 结果增量落盘，实时明细可筛选、分页、查看详情

### 分析

- 按任务选择记录，左右箭头切换上一条 / 下一条
- 通过率按有效样本计算，调用失败 / 模型超时 / 解析失败单列为「未计入」
- 结果按评测提示词输出聚合，分类分布可点击筛选
- 明细表支持按结果、分组、分类筛选和关键词搜索
- 点任意一行看详情：原始数据、实际发送的消息、被测输出、裁判原始输出、判定原因
- 详情里有两侧的 token 用量和裁判生成速度

### 导出

- 导出 CSV 或 JSON，支持大结果分块写盘
- 导出完整报告：一个 xlsx，包含概览、错误分类、明细三个 sheet，带方案名、数据集名、标题条、指标卡、状态色和冻结表头

### 自动迭代

- 自动迭代脚本和说明随应用安装
- 只用 Python 标准库，Python 3.8 以上即可
