# 批量评测台

本地桌面工具：用你自己的 LLM API 批量跑评测数据，按评测提示词给出的分类聚合结果，并可视化定位问题。

## 直接运行

双击 `src-tauri\target\release\batch-eval.exe`，免安装。

要生成安装包（网络通畅时），在项目根目录执行：

```bash
npx tauri build
```

## 开发模式

在项目根目录执行：

```bash
npm install
npm run tauri dev
```

## 使用流程

**① API 配置**

- 被测模型：要评的那个 API
- 评测模型（裁判）：给出分类与原因的 API，建议 temperature 设 0 让判定稳定
- 两个可以填同一个 API，点「同步到评测模型」一键复制
- 协议支持 OpenAI 兼容（`/chat/completions`）与 Anthropic（`/v1/messages`）
- 可配：上下文长度、max_tokens、temperature、top_p、超时、自定义请求体/请求头（JSON 对象，合并进 body）
- 填完点「测试连接」验证

**② 提示词**

- 主体提示词：被测的那份提示词
- 用户消息模板：用 `{{列名}}` 注入数据列，导入数据集后可一键生成
- 评测提示词：裁判逐条调用的提示词，必须含 `{{input}}` 与 `{{output}}`，并输出带 `pass` 和分类的 JSON

没有现成的评测提示词或数据集时，在 Claude Code 里用 `eval-prompt-designer` / `gen-test-data` skill 生成，再把结果导回来：评测提示词贴进本页，数据集存成 `.json` 后在「数据集」页导入。

评测提示词需要约定：`{{input}}` 会被替换为「本条输入 + 主体提示词」，`{{output}}` 替换为被测模型输出，输出的 JSON 需含 `pass` 与 `errorType`。

**③ 数据集**

- 支持 CSV / TSV / Excel / JSON / JSONL / 纯文本，也可直接粘贴
- 中文编码自动识别（UTF-8 失败回退 GB18030）
- 列名为「数据组状态」的列会被识别为分组列，分析页用它做交叉热力图
- 勾选要注入提示词的列

**④ 运行**

- 并发数建议 4~8，太高容易被限流
- 支持运行中取消、断点续跑、失败项单独重跑

**⑤ 分析**

- 通过率环图、分类分布条形图
- **分组 × 分类热力图**：看出哪类测试数据总出哪类问题，点格子直接下钻
- 明细表点任意一行打开详情：原始数据、实际发送的消息、被测输出、评测原始输出、证据与原因
- 导出 CSV（Excel 直开）或 JSON

## 分类从哪来

工具不内置任何分类体系。分类完全来自你的评测提示词输出的 `errorType` 字面，按它聚合。

只有三种情况用工具自己的兜底分类，且与你的分类区分开：

- `被测模型调用失败` —— 被测 API 报错
- `评测模型调用失败` —— 裁判 API 报错
- `评测输出解析失败` —— 裁判返回的内容实在解析不出结构

评测输出解析做了三层容错：剥代码块 → 括号配平提取 JSON → 字段名大小写/下划线/同义词兼容。

## 数据存在哪

全部在 `%APPDATA%\com.batcheval.app\` 下，按用途分文件，重开应用自动恢复：

```
settings.json              配置、提示词、列选择、主题（KB 级）
dataset.json               数据集（可几十 MB，单独存，不拖慢配置保存）
runs/current/meta.json     当前这次运行的元信息（总数、状态、起止时间）
runs/current/results.jsonl 每跑完一条追加一行，崩溃/取消都不丢
```

- 只保留「当前一次运行」，新跑会清空上一轮结果。
- 结果按 `index` 去重，重跑同一行以最后一行为准；跑到一半杀进程，下次启动会把缺失的最后半行识别为坏行跳过并提示。
- 旧版本把数据集和结果塞在 `settings.json` 里，新版本首次启动会自动迁移到上面几个文件。
- API Key 明文存在本地，不会上传到任何地方。

## 大批量（万条级）

- 数据集超过 2 万条会提示调整并发/超时；超过 10 万条要求二次确认。
- 分析页明细分页，默认 50 条/页，可切 100 / 200，支持跳页；筛选和搜索只作用于当前加载的结果集。
- 进度事件按 10 条 / 250ms 批量推送，运行中随时可切到「分析」页看已出结果。
- 遇到 429 / 503 会按 `Retry-After` 全局限速并带抖动退避重试，不会所有并发一起冲。
- 导出 CSV / JSON 分块写盘，1 万条也不会一次性拼出大字符串。
